# fixed_point_golden_check — 用 ILA 实测数据复算定点算法

## 适用场景
FPGA 中实现了定点算法（PID、滤波、坐标变换等），仿真已通过，但需要证明**板上实际运行**的结果与设计公式一致，例如为报告提供可复现的证据。

## 方法
1. ILA 同时抓取算法的**输入**（如 PD 样本、目标值）、**有效标志**（`sample_tick`、使能）和**输出**（修正量）。
2. 导出 CSV，用 Python 按 RTL 中完全相同的位宽、移位、饱和规则复算。
3. 输出寄存器通常晚 1 拍，比较时取下一行的输出值；若下一拍使能已撤销，该次结果不应输出，单独标注而不是判为失败。
4. 全部一致时打印 `RESULT=PASS`，便于写入回归或文档。

本目录的 `verify_pid_from_ila.py` 是本项目 Q8 PID 的实例：

```
e[n] = P_ref − P[n]
I[n] = sat_I( I[n−1] + Ki·e[n] )
u[n] = sat_u( (Kp·e[n] + I[n] + Kd·(e[n] − e[n−1])) >>> 8 )
```

## 使用方法
```bash
python3 verify_pid_from_ila.py ../../data/ila/ila_capture_frame.csv --kp 256 --ki 8 --kd 0 --limit 1000
```
迁移时修改脚本中的列名（`w_pd_adc_sample_tick` 等）与公式部分；注意 ILA 导出的 HEX 列需要按位宽转换为有符号数，Python 的 `>>` 对负数是算术右移，与 Verilog `>>>` 一致。

## 失效条件
- ILA 深度有限，只能覆盖少量更新；需要统计意义时应多次触发或在 RTL 中加入计数器。
- 若 ILA 采样时钟与算法时钟不同，需要先对齐有效标志。

## 已验证的效果
本项目一帧中 PID 共更新 3 次，前 2 次复算值与 ILA 记录完全一致（29、162），第 3 次发生在 PID 撤销前一拍，复算值 588 未输出，与设计行为一致，结果 `RESULT=PASS`，对应报告表 3-6。

## 来源
撰写报告时需要证明"PID 运算正确"，仿真结果不足以说明板上运行情况，于是改为用实测数据逐点复算。第 3 次更新发生在 PID 撤销的前一拍，若只比较修正量会被判为不一致，必须同时检查下一拍的使能信号，因此加入了第 3 条规则。

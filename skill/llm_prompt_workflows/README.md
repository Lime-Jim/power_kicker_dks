# llm_prompt_workflows — 与大模型协作的任务模板

以下模板来自本项目与大模型协作完成技术文档、数据分析和图表的过程（详见 `../../report/llm_collaboration.md`）。每个模板都包含"要求模型做什么"和"人必须把关什么"，可直接替换方括号中的内容使用。

## 模板 1：技术文档一致性审查

**任务**：
> 请通读 [文档]，对照 [原始数据：ILA CSV / 示波器 CSV / 综合报告] 检查以下内容，逐条列出不一致之处，给出原文、数据依据和建议修改，不要直接改写结论：
> 1. 所有数值（时间、电压、资源、时序）是否与原始数据一致；
> 2. 同一指标在摘要、正文、表格中的写法是否一致；
> 3. 时间顺序类表述是否把多个事件合并成一个；
> 4. 图号、表号、参考文献编号是否连续且有对应；
> 5. 有无学校、教师姓名等提交要求禁止出现的信息。

**人必须把关**：物理结论和实测数据的口径（例如某指标来自哪一次测试）由人确认；模型提出的疑问逐条回复后再修改。

**已验证的效果**：发现了"120 ns 内重新开始扫描和 kick"与 ILA 记录不符、参考文献 [18] 缺失、同一指标两种口径并存、数量级计算错误等问题。

## 模板 2：用实测数据复算算法

**任务**：
> 这是 [ILA / 示波器] 导出的 CSV，列含义为 [列说明]。RTL 中算法为 [公式，含位宽、移位、饱和]。请写一个 Python 脚本按 RTL 规则复算，逐点与实测输出比较；输出寄存器晚 1 拍；若某次结果因使能撤销未输出，单独标注。最后打印 PASS/FAIL。

**人必须把关**：公式与位宽必须从 RTL 原文复制给模型，不能让模型凭描述猜测。

**已验证的效果**：生成 `../fixed_point_golden_check/verify_pid_from_ila.py`，3/3 一致。

## 模板 3：实测波形出图

**任务**：
> 读取 [CSV]，绘制 [通道]。要求：主图显示 [时间范围]，在 [事件] 附近加放大小窗，主图上用方框标出放大区间；标注 [持续时间] 时用数据中的边沿位置计算，不要目测；中文字体用 [字体]；导出 300 dpi PNG。并告诉我每个标注数值是如何从数据中得到的。

**人必须把关**：标注数值与报告正文一致；放大框为便于辨认而放宽时，在图注中说明。

## 模板 4：提交前格式与匿名检查

**任务**：
> 检查 [docx]：上下标是否使用了 Unicode 特殊字符（如 ₃、⁶），公式能否在 Word 外正常显示，目录页码是否需要更新，全文是否出现学校名、教师名。列出位置，不要改动正文内容。

**人必须把关**：最终 PDF 由 Word/WPS 导出并人工翻阅一遍。

## 使用边界
- 大模型擅长：批量数据处理与作图、一致性审查、格式修改、脚本编写。
- 大模型不能替代：实测数据本身、物理参数的真实性、"某结论是否成立"的最终判断。所有模板都要求模型"列出疑问、给出依据"，而不是直接改写结论。

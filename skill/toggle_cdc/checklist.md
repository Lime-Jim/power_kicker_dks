# 多位数据跨时钟域检查清单

逐项打勾后再上板：

- [ ] 源数据在两次更新之间是否**完全不变**？（必须先写保持寄存器，不能直接跨组合逻辑输出）
- [ ] 只同步了 1 位控制信号（toggle），多位数据**没有**经过同步器？
- [ ] 同步器寄存器标注了 `(* ASYNC_REG = "TRUE" *)`，级数 ≥ 2（高频目标域建议 3）？
- [ ] 计算了 `T_load = (S + N + 1) × Td`，并确认 `T_load < 源数据最短保持时间`？写下两个数字和余量。
- [ ] 两个时钟都是**连续运行**的？任一时钟可能停顿时，复位或握手策略是否已覆盖？
- [ ] 目标域每个源数据只产生**一个** tick？后级计数、积分是否只在 tick 时更新？
- [ ] 两个时钟域的复位各自"异步置位、同步释放"？
- [ ] 仿真覆盖了：连续多笔数据、跨域延迟上下界、复位中途释放、两个时钟频率比的边界值？
- [ ] Vivado CDC 报告中该通路被识别为预期类型（如 CDC-3 + CDC-15），没有未解释的 CDC-1/CDC-7？
- [ ] 文档中写明了这是"理想 RTL 时序推导"，不是物理签核？

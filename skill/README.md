# skill — 技能包

本目录整理了本项目开发、调试与文档撰写过程中沉淀的可复用经验。每一项都写明适用场景、使用方法、失效条件、已验证的效果，以及它是从哪些失败或观察中总结出来的。除标注"本项目专用"的参数外，各项不依赖本作品的题目，可直接用于其他 Vivado / FPGA 工程。

| 目录 | 类型 | 一句话说明 | 适用范围 |
|---|---|---|---|
| `vivado_portable_project/` | 案例模板 | 用源文件清单 + XPR 模板可移植地重建 Vivado 工程，避免 `create_project -force` 删源码 | 任意 Vivado 工程 |
| `vio_param_save_restore/` | 脚本模板 | VIO 参数一键保存/恢复，兼容有符号探针与旧补码存档 | 用 VIO 调参的板级实验 |
| `ila_state_code_trigger/` | 设计模板 | 增加只读状态码模块，ILA 以状态跳变触发，稳定抓到"进入闭环"等关键时刻 | 含状态机的实时控制系统 |
| `toggle_cdc/` | 设计模板 + 检查清单 | 多位数据跨时钟域：保持寄存器 + 1 位 toggle 同步 + 延迟装载，附适用条件计算 | 低速更新的多位数据跨域 |
| `regression_with_sentinel/` | 校验框架 | 一键回归仿真：PASS 哨兵字符串、故意注入错误、硬件 IP 行为模型替身 | Vivado xsim 工程 |
| `fixed_point_golden_check/` | 校验脚本 | 用 ILA 实测数据按定点公式复算算法输出，逐点比对 FPGA 结果 | 任意定点算法（PID、滤波器等） |
| `scope_csv_tools/` | 脚本 | 读取 Siglent 示波器 CSV 并绘图，统一处理文件头与单位 | 示波器实测数据整理 |
| `external_io_timing_gate/` | 流程模板 | 缺少板级数据时，外部 IO 时序明确标为 PROVISIONAL，不把空值当 0 ns | 高速 ADC/DAC 接口工程 |
| `llm_prompt_workflows/` | 提示词工作流 | 与大模型协作完成技术文档一致性审查、实测数据复算、图表制作的任务模板 | 竞赛 / 项目文档撰写 |
| `pitfalls.md` | 踩坑清单 | 28 条结构化的常见错误，含触发条件、现象、排查与解决 | 通用 |

## 如何使用

1. 先读 `pitfalls.md`，对照自己的工程快速排雷。
2. 需要某项能力时，进入对应目录阅读 `README.md`，按"使用方法"一节操作；脚本中标注 `# 修改此处` 的位置需要按自己的工程调整。
3. 本项目中这些技能的实际用法可在仓库 `src/` 与 `data/scripts/` 中找到完整实例。

## 技能的提炼过程

这些技能并不是事先设计的，而是在问题出现后逐步总结的：

- **从失败与风险中总结**：例如 `create_project -force` 会清空源码目录、VIO 有符号探针保存后恢复成错误值、托管 XDC 中 `source` 命令不被执行、仿真 `$fatal` 不一定传递退出码。每次故障排查后，把触发条件和解决办法写进 `pitfalls.md`，并把修复固化为脚本或模板。
- **从观察中总结**：例如 ILA 难以抓到"进入 PID"这一瞬间，于是增加只读状态码并以状态跳变触发；报告中的时间结论容易与原始记录不一致，于是形成"回到原始数据逐点复算"的校验脚本和提示词工作流。
- **如何验证有效**：每项技能都在本项目中实际使用过，已验证的效果写在各自的 README 中（如回归平台检查项数、ILA 复算 3/3 一致）。
- **如何确定边界**：每项都写明失效条件。例如 toggle 跨域结构只在"源数据保持时间大于目标域装载延迟"时成立，时钟会停顿或更新更快时应改用异步 FIFO。
